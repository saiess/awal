## Dependency scope and restrictions

`scripts/audit_dependencies.py` archives every installed distribution's declared license, license classifiers, bundled license files, and hashes. Its `bundled_assets` records also identify the installed spaCy model files, eSpeak DLL, FFmpeg executable, and Perth's `perth_net_250000.pth.tar` watermark checkpoint/config by SHA256. Perth's checkpoint is bundled in the pinned upstream MIT project without a separate weight-license override found in the reviewed source. These small auxiliary assets remain inside the gitignored virtualenv packages; the 6.5 GB of candidate TTS/preset assets are cached outside the repository. Installation reports identify exact wheel URLs/hashes; `requirements-*.lock.txt` captures resolved versions. An upstream reviewed Git commit is not a claim that an installed PyPI wheel is byte-identical to that Git tree: installed wheel evidence is kept separately.

- Kokoro/Misaki: Apache-2.0. PyTorch/torchaudio: BSD-family declarations plus retained third-party notices; CUDA components retain their own terms. Transformers/tokenizers/safetensors: Apache-family declarations. Keep the actual notices with redistributed code/weights.
- `phonemizer-fork==3.3.2`: GPLv3-or-later, bundled license archived. `num2words==0.5.14`: LGPL declaration, bundled license archived. `certifi`: MPL-2.0. These components must not be described as MIT/Apache-only.
- `espeakng-loader==0.2.4` omits license metadata/text from its wheel. Official source commit `0ddc87adf77e5850d7eeb542ac8a87d421b64daa` declares MIT and its pyproject reports version 0.2.4; that evidence is archived. The DLL reports **eSpeak NG 1.52.0**, not the older 1.51 mentioned on an upstream release page. GPLv3-or-later license evidence is pinned to the official 1.52.0 tag/commit `4870adfa25b1a32b4361592f1be8a40337c58d6c`. Binary source/build correspondence is not independently reconstructed; retain this provenance limitation before redistributing a packaged binary.
- spaCy's official `en_core_web_sm==3.8.0` wheel declares MIT. Its `LICENSES_SOURCES` lists OntoNotes as commercially licensed by Explosion, plus additional source notices. Both wheel license and source notices are archived; the underlying training corpus is not independently licensed or redistributed here.
- imageio-ffmpeg's Python wrapper is BSD-2-Clause. Its Windows FFmpeg 7.1 binary reports `--enable-gpl --enable-version3`, so the **binary is GPL**, not BSD. `ffmpeg-binary-license.txt` contains its own license output. Binary SHA256: `2ce797a0f88d7f067180338fb227f7b1928ea727bd9a4d7a1d022f7c52af71a3`. No export processing uses this binary in the benchmark.
- Chatterbox's Perth dependency is pinned to official MIT source `ff1c8ac55a976971245cdd53c18d6131ca00d993`, instead of mutable upstream `master`. Keep the built-in watermarking behavior. `pykakasi==2.3.0` declares GPLv3-or-later; `soxr==1.1.0` declares LGPL-2.1-or-later. Other resolved dependency declarations and bundled license texts are archived. Both models pass native CUDA loading. Reference consent has now been confirmed; quality remains subject to listening review.

GPL/LGPL dependencies are not automatically noncommercial exclusions. Their code/binary distribution obligations must be respected. The GNU project's [output guidance](https://www.gnu.org/licenses/gpl-faq.en.html#GPLOutput) distinguishes program licensing from ordinary output; it does not clear an underlying voice. This phase is local evaluation, not distribution of a packaged application. No assertion is made that distributing this whole stack as proprietary software would be cleared.
